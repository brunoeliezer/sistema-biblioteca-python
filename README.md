Sistema de Gerenciamento de Biblioteca Digital
Sistema criado para a disciplina de Programação para Ciência de Dados. Ele gerencia documentos digitais, organizados por ano de publicação e tipo de arquivo.

Funcionalidades
Listar: Exibe a hierarquia de pastas.

Adicionar: Move arquivos para o acervo.

Renomear: Altera o nome de arquivos.

Remover: Apaga documentos.

Abrir: Abre o documento no leitor padrão do sistema.
