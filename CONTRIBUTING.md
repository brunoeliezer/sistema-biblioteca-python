Guia de Contribuição
Para contribuir com este projeto, siga os passos:

Faça um Fork do repositório.

Crie uma branch: git checkout -b minha-melhoria

Faça os Commits de forma clara: git commit -m "feat: adiciona nova função"

Envie as alterações (Push): git push origin minha-melhoria

Abra um Pull Request explicando suas mudanças no GitHub.
